# Paper sections: introduction, related work, methodology, set-up, results

`main.tex` builds a standalone draft. Each section in `sections/` can be `\input` into a full
paper.

```
sections/introduction.tex  Introduction (motivation, three open problems, contributions)
sections/related.tex       Related work (FFIA, AV fusion, hypercomplex networks, efficient models and KD)
sections/method.tex        Methodology (Eqs. 1-18, Figs. 1-5)
sections/experiments.tex   Experimental set-up (data, three protocols, teachers, baselines, metrics)
sections/results.tex       Results (tables and figures, with \todo notes on claims to confirm)
tables/*.tex, macros.tex   GENERATED by scripts/make_paper_assets.py
figures/*.pdf              architecture figures (scripts/export_svg_figures.js) + GENERATED result plots
refs.bib                   bibliography; entries marked VERIFY need checking against the publisher record
```

## Workflow

```bash
# 1) run experiments (each writes runs*/<name>/result.json)
SEEDS="0 1 2" bash scripts/run_ablations.sh configs/student_hyper.yaml      # A_*, B_*, C_*, D_*, G_*
bash scripts/run_teacher_ablation.sh                                         # teacher_T*, student_from_T*
VIDEO_ROOT=... AUDIO_ROOT=... bash scripts/run_protocols.sh                  # P_uffia, P_kfold, P_grouped
for s in 0 1 2; do python train.py -c configs/student_hyper_kd.yaml --set name=student_hyper_q_kd_s$s --set seed=$s; done

# 2) regenerate every table, figure and number in the text
python scripts/make_paper_assets.py           # scans every runs*/ folder

# 3) build the PDF
cd paper && latexmk -pdf main.tex
```

Runs named `<name>_s<k>` or `<name>_fold<k>` are averaged into one row (mean ± std). The names
that each table expects are listed at the top of `scripts/make_paper_assets.py`.

Before submission:
- Replace or delete every `\todo{...}` (orange in the draft). Set `\showtodosfalse` in `main.tex`
  to hide them.
- Check the bibliography entries marked VERIFY, and the published numbers marked † in the
  main table.
